# Bản lưu trước khi chuyển sang React

`static/` giữ các trang HTML đầy đủ cùng thư mục assets để xem lại giao diện cũ. `original-assets/` là tài nguyên gốc được chuyển khỏi root. `react-starter/` giữ source mẫu React trước khi thay thế.

Các tệp này chỉ phục vụ đối chiếu và khôi phục. Ứng dụng mới không import HTML hoặc JavaScript từ thư mục này.
